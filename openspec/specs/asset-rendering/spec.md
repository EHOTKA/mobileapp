# asset-rendering Specification

## Purpose

Описывает загрузку растровых ассетов из `assets/img` с лимитом памяти и порядок отрисовки
кадра на `Canvas`. Реализация — `GameView.loadBitmaps/decodeSampled/drawGame`
(`app/src/main/java/com/example/game/GameView.kt`).

## Requirements

### Requirement: Спрайты декодируются с ограничением размера

Приложение MUST декодировать растровые изображения из `assets` с передискретизацией по
степеням двойки так, чтобы ни одна сторона не превышала разумного предела (512 px), и
MUST читать только границы изображения на первом проходе.

#### Scenario: Большой исходник
- **WHEN** ассет имеет размер 2048×2048
- **THEN** выбран `inSampleSize` не менее 4, и в память попадает растр ≤512 px по стороне

#### Scenario: Ассет отсутствует
- **WHEN** файл по пути в `assets` не открылся
- **THEN** в карте битмапов сохраняется `null`, а приложение не падает

#### Scenario: Предел объявлен до init
- **WHEN** конструктор `GameView` выполняет `init`
- **THEN** константа предела уже инициализирована и не равна 0

### Requirement: Required-sprite inventory

Игра MUST загрузить фиксированный набор спрайтов для всех визуальных сущностей: дом,
газета, барьер, машина игрока и препятствия, велосипед, сердце, монета.

#### Scenario: Проверка инвентаря
- **WHEN** `loadBitmaps` завершён
- **THEN** в карте есть ключи `house`, `paper`, `barrier`, `car`, `bicycle`, `heart`, `coin`,
  `obs_car`, `obs_box`

### Requirement: Порядок отрисовки кадра фиксирован

Кадр MUST рисоваться слоями в порядке: фон (трава), дорога с разметкой, деревья, дома,
препятствия, машины, бонусы, газеты, частицы, погода, скоростные линии, персонаж,
индикатор модификатора — чтобы персонаж был поверх объектов.

#### Scenario: Полная отрисовка
- **WHEN** вызван `onDraw` при активном забеге
- **THEN** слои рисуются в указанном порядке, каждый объект получает эллиптическую тень под собой

#### Scenario: Разметка полос скроллится
- **WHEN** `roadOffset` растёт со скоростью дороги
- **THEN** пунктирные линии полос смещаются вниз с циклом 180 px, сегмент по 100 px

### Requirement: Тряска камеры смещает весь кадр

Пока `cameraShakeTime > 0` отрисовка MUST смещать canvas на случайное значение до ±15 px
по каждой оси.

#### Scenario: Тряска после удара
- **WHEN** `cameraShakeTime > 0` и рисуется кадр
- **THEN** перед отрисовкой применяется `canvas.translate` со случайным смещением

#### Scenario: Тряска закончилась
- **WHEN** `cameraShakeTime <= 0`
- **THEN** смещение не применяется

### Requirement: Декорации вне дороги генерируются случайно

Игра MUST размещать 12 деревьев по обе стороны от дороги и прокручивать их вместе с миром.

#### Scenario: Инициализация деревьев
- **WHEN** `GameView` создан
- **THEN** список содержит 12 деревьев со случайной стороной и Y-координатой
