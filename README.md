# Почтальон Драйв (Postman Drive) — Android Native

Динамичная 2D-аркада с видом сверху, написанная на чистом Kotlin с использованием Android Canvas.

## 🛠 Технологии
- **Язык**: Kotlin
- **Графика**: Android Canvas (120 FPS через `Choreographer`)
- **UI**: Native XML (Glassmorphism design)
- **Звук**: `SoundPool` (эффекты), `MediaPlayer` (фоновая музыка)
- **Хранение**: `SharedPreferences` (рекорды)

## 🏗 Архитектура проекта

### 1. `MainActivity.kt` — Управление UI и Жизненным циклом
Отвечает за переключение экранов (Меню, Игра, Пауза), управление музыкой и обновление статистики через слушателей (`listeners`).

### 2. `GameView.kt` — Игровой Движок
Основное ядро игры. Здесь реализовано:
- **Game Loop**: Бесконечный цикл отрисовки и обновления логики.
- **Entity System**: Логика домов, препятствий, бонусов и игрока.
- **Collision Detection**: Проверка столкновений и попаданий.
- **Procedural Animation**: Покачивание и наклон персонажа через математические функции.

### 3. Ресурсы (`assets/img`)
- `character.png`: Игрок (вид сверху).
- `house.png`: Цели для доставки.
- `barier.png`: Препятствия.
- `paper.png`: Бонусы и снаряды.
- `heart.png`: Иконка уведомлений.

## 📝 Как развивать проект
Для внесения изменений рекомендуется придерживаться структуры `Entity` в `GameView.kt`. Все новые игровые объекты должны наследоваться от базового класса или реализовывать методы `update` и `draw`.
